          Technische Mängel im alten Code
          • Das Monats-Dropdown ruft filterData() auf – die Funktion war nirgends definiert, der Filter hatte also keine Wirkung.
          • Der Code brach mitten in der Belgien-Zeile ab (14,), alle schließenden Tags fehlten.
          • Kopfzeile nannte „Januar – Oktober“, die Daten reichten aber nur bis September.
          • „Top 10“ zeigte nur 6 Einträge, Platz 6 fehlte; „EU-27“ und „EU-27 + UK“ wurden vermischt.
          • Tailwind wurde über das Play-CDN geladen, das nicht für den Produktivbetrieb gedacht ist; Flaggen-Emojis werden unter Windows als Buchstaben angezeigt.
